# Reten Records

Reten Records is the official music and media web/app foundation for RetenRecords.com.

This is not a static-only project. The first live version is a simple launch shell, but the long-term purpose is to support releases, artist pages, auditions, interviews, live sessions, collaborations, previews, catalog access, and future media workflows.

## Core Identity

Reten Records is the dedicated music and media brand.

- RetenRecords.com = music, media, releases, auditions, interviews, live sessions, collaborations, artist pages, previews, and catalog access
- CyberCrowd.net = platform, WDIG, Magic Cursor, access passes, tools, devices, and broader ecosystem infrastructure

The two brands are related by ownership and vision, but they remain technically separate unless a future integration is intentionally approved.

## Current Phase

Phase 1 is the launch foundation.

The immediate goal is to keep RetenRecords.com simple, live, and verifiable:

- homepage loads
- HTTPS works
- robots.txt works
- sitemap.xml works
- Cloudflare deployment remains clean
- no random DNS records
- no unnecessary platform wiring

## Future Direction

Reten Records may grow into a music and media operations hub for:

- release pages
- artist pages
- music previews
- cover art
- full-length catalog access
- auditions
- interviews
- live sessions
- collaborations
- studio updates
- media submissions
- multi-platform live routing

## Not Active Yet

These are intentionally not active in the current phase:

- Stripe
- R2 protected music storage
- subscriptions
- paid catalog access
- CyberCrowd integration
- x402
- MCP
- OAuth
- agent endpoints
- advanced Worker routes

## Build Rule

Build as we grow.

Do not overbuild the foundation before the domain, deployment, content structure, and public identity are stable.
